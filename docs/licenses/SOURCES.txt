This software is based in part on the work of the Independent JPEG Group.

Berkeley and its contributors.

The client contains Ogg, Vorbis, Opus, opusfile and zlib code. The dedicated
server contains zlib code. Both renderers contain JPEG code. The client and
renderers use the bundled SDL2 2.32.8 runtime; its file version was checked.
These dependencies were checked against build-bots-msvc/CMakeCache.txt and
the Release link command records. Retrieved notices preserve upstream bytes.

The Windows HTTP implementation uses WinINet; libcurl is not linked into
this build. OpenAL is loaded optionally from an installed runtime through
USE_OPENAL_DLOPEN; no OpenAL library is included in the portable package.
The minizip build defines NOUNCRYPT and excludes Info-ZIP crypt code.

The repository's COPYING.txt and GPL accompany the game code. Its CC and
the original game-data credit/license files accompany the bundled media.
